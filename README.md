# Projeto-Biblioteca-C++

Código que inicializa uma estante de livros, permite ao usuário cadastrar livros, remover livros e trocar livros de posição.

## Tecnologias e conceitos

- Linguagem **C++**
- Uso de **containers STL**
- Uso de **structs** para representar os livros

## Funcionalidades

- Inicializar a estante de livros
- Cadastrar livros
- Remover livros
- Trocar livros de posição
